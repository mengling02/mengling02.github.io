# Hello World

欢迎来到我的博客！这里是用 GitHub Pages 搭建的个人站点。

## 如何写文章

1. 在 `posts/` 目录下创建 `.md` 文件
2. 在文件开头添加 YAML front matter（标题、日期、标签）
3. 推送到 GitHub，GitHub Actions 会自动构建和部署

也可以直接去 `/admin` 后台在线写文章并发布。
